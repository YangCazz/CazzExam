# 备考使用指南（2026-11 系统架构设计师）

> 目标：三科（综合知识 / 案例分析 / 论文）当次全部 ≥45 分，成绩不保留。
> 距考试约 11 周，本指南给出每天怎么用、三科怎么攻、11 周怎么排。

## 一、系统速览
- 知识库：55 个大纲知识点（树形 + 图谱 26 条关联，薄弱点标红）
- 题库：74 题（60 单选 + 6 案例 + 8 论文）——真题 PDF 放进来后可批量导入扩充
- 练习模式：知识点 → 关联题 → 即时反馈（对错/解析/自动进错题本）
- 模拟考试：三科模板限时全真，报告按知识点得分率 + 错题回顾 + 历史回看
- 错题本：SM-2 间隔复习 + 错因归因（知识性/理解偏差/审题失误/方法错误/其他）+ 反思
- 统计画像：14 天趋势、错因分布、薄弱 Top10、掌握度热力
- 论文专项：真题限时写作、素材库、ADR 记录、AI 批改（配 key 后）
- 学习计划：按考试日期一键生成四阶段计划；首页显示"今日任务"

## 二、每天 30-60 分钟使用流程
1. 打开 http://127.0.0.1:5173（start.cmd 一键启动）
2. 看首页「今日任务」：待复习错题数 + 薄弱知识点
3. 先去「错题本」复习队列：看题 → 回忆 → 自评（忘了/模糊/记住了）→ 归因写反思
4. 再点「练习模式」练薄弱知识点（或直接「模拟考试」刷 20-30 题）
5. 交卷后看报告，**当晚给错题归因**（拖到第二天就忘了当时思路）

## 三、三科备考策略
| 科目 | 策略 |
|---|---|
| 综合知识（上午） | 广覆盖：每天 20-30 题；按知识点得分率补漏；错题归因到位 |
| 案例分析（下午一） | 每周末 1 套；重点练 4 类题：架构风格识别 / 质量属性场景 / 微服务改造 / 高可用与可靠性；先自评再对照参考答案 |
| 论文（下午二） | 每 1-2 周 1 篇限时写作（120 分钟、2500 字+）；用素材库攒项目经历；配 AI key 后让 AI 分档批改 |

## 四、11 周冲刺节奏（与「学习计划」自动生成一致）
1. **基础学习（约 2 周）**：把 55 个知识点过一遍，重点看图谱中的"前置/主线"关系，建立知识骨架
2. **真题精练（约 3 周）**：真题批量入库后，按章节刷透；错题归因常态化
3. **套卷模拟（约 3 周）**：每周 2-3 套全真（上午 75 题限时 150 分钟）
4. **错题冲刺（约 2 周）**：只攻错题本 + 薄弱知识点 + 论文模板打磨；最后一周做 1-2 套找手感

## 五、数据与维护
- 数据文件：backend/data/study.db（SQLite，WAL）
- 备份：python backend/scripts/backup_db.py（保留最近 20 份）；建议加入计划任务每天跑一次
- 真题导入三步：pdf_extract.py（PDF→文本）→ 整理成 import_template.xlsx 模板 → import_tool.py xlsx2json → import_json.py 入库
- AI 配置：编辑 backend/app/config.py 的 ai_base_url / ai_api_key / ai_model（DeepSeek/通义等 OpenAI 兼容），重启后端
- 健康自检：python backend/scripts/health_check.py

## 六、常见问题
- 打不开 5173：运行 start.cmd；或手动开两个窗口（backend 起 uvicorn，frontend 起 vite）
- 页面报错：看后端控制台日志；数据异常可恢复最近备份（data/backup/）
- 题目不够刷：把真题 PDF 放进工作区，告诉我路径，我帮你批量入库
