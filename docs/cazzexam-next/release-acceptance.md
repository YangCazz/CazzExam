# CazzExam Next 验收与演进

此表区分发布范围、验证证据和后续规划。发布不以页面数量或题目总数为完成标准。

## 第一个里程碑：能从问题走到理解

| 验收项 | 用户能做什么 | 通过条件 |
| --- | --- | --- |
| E01 探索入口 | 从关键词、主题或问题开始，不先做诊断 | 无考试倒计时、待办墙或强制选考；打开后可直接阅读示例 |
| E02 搜索 | 用中文标题、别名或常见英文缩写找到概念 | 查询有结果时能打开详情；无结果、读取失败不混淆；返回后保留查询及可恢复的视角 |
| E03 阅读 | 读懂概念是什么、为什么这样做、代价是什么 | 至少一条原创解释、一个场景、一个边界或反例；来源或原创标记可辨；可直达链接 |
| E04 知识关系 | 看到另一概念为何相关，而不是只见推荐标题 | 每条关系有类型和理由；键盘、触屏可打开，返回后不丢导航上下文 |
| E05 资格视角 | 在全部内容和特定资格之间切换 | 资格筛选不创建重复概念；示例映射不写成官方覆盖；没有经核映射就如实显示 |
| E06 跨屏与异常 | 用桌面或手机读完；网络失败后重试 | 至少验证桌面与约 390px 手机宽度，额外检查 320px、焦点、换行、浏览历史和错误重试。不靠颜色或悬停传达关键信息 |
| E07 轻量部署 | 按 README 在独立目录运行新版 | 启动方式、版本要求、示例数据和端口可复现，不使用旧版学习数据库；后端接口测试与前端构建通过，没跑的检查另列 |

建议用一条原创链路作为验收入口：**微服务拆分 → 数据一致性 → 事务发件箱／幂等消费**。教材引用、示范结论及资格映射分别标识；不把示例写成真题或声称代表某年考频。首批一条读得顺的链路比大量空页面重要。

## 后续里程碑

1. **探索可积累**：个人笔记、收藏与书架。先验证重启后找回、编辑失败保留草稿、导出与删除，再评估登录和同步。没有持久化之前不展示“已保存”。
2. **练习能解释**：可选原创练习在作答后解释选择条件与常见误区；题源经核与使用权单独标注。缺失或冲突项可保留来源方便核对，不计分，也不默认标为真题。
3. **考试视角可信**：展示考纲版本、适用期次和出处。趋势以明确样本和覆盖缺口为前提；不把重复转述当多份证据，不给未核年份统计。
4. **升级可回退**：只有新版主流程验收后，才设计旧版笔记/收藏迁移。迁移先做副本、差异报告、失败回退；不自动搬入第三方题库或旧任务数据。

## 验证记录约定

每批记录提交 SHA、代码范围、运行过的命令、验证的设备尺寸，以及仍未验收的行为。分别标明**接口通过、前端构建通过、真实浏览器流程通过、发布完成**，禁止互相代替。公开文档和代码以 GitHub 远端为准；私人核验表继续独立留存。默认分支和部署都是另一步，不因新版分支更新而自动发生。
