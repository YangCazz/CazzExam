## 1. 背景与目标

### 1.1 背景
- 备考目标：2026 年 11 月参加软考高级「系统架构设计师」，三个科目（综合知识 / 案例分析 / 论文）须**当次全部 ≥45 分**，单科成绩不保留。
- 系统定位：个人单机备考工具。真题、错题、反思、论文素材等数据资产归本人所有，存放本地。

### 1.2 四个核心需求 → 系统能力映射

| 用户需求 | 系统能力 | 主要模块 |
|---|---|---|
| 知识点复习 | 结构化知识库 + 关联例题 + 掌握度反馈 | 知识库 |
| 知识点串联 | 知识图谱：主线 / 前置 / 相关 / 包含 | 知识图谱 |
| 考试模拟 | 三科机考模拟 + 自动判分 + 薄弱点报告 | 模拟考试 |
| 错题整理与思考 | 错因归因 + 反思笔记 + 间隔复习 | 错题本 |

### 1.3 成功标准（可度量）
- S1：历年真题（2016–2025，以能获取到的为限）全部入库，可检索、可组卷。
- S2：知识图谱覆盖考试大纲全部知识点，主线（架构设计）清晰可见。
- S3：模拟考交卷后 2 分钟内出报告，自动圈定薄弱知识点并生成错题。
- S4：错题闭环完整：每道错题都有归因与反思；间隔复习调度正常运行。
- S5：论文 AI 批改可给出分档评分 + 改进建议；个人素材库可支撑常见论文题。

## 3. 总体架构设计

### 3.1 架构风格选型（ADR-001 摘要，详见附录 A）
- **形态**：本地 Web 应用 = 浏览器 + 本地后端进程 + SQLite。
- **架构风格**：分层架构（表现层 / 应用层 / 领域层 / 基础设施层），组件内聚、易测试、易维护。
- **备选**：纯前端 PWA（数据管理弱、大题库导入困难）；在线服务（开发运维工作量大、数据不在本地）。

### 3.2 技术栈（默认方案，待确认）

| 层 | 选型 | 理由 |
|---|---|---|
| 后端 | Python 3.12 + FastAPI + SQLAlchemy | 单机一条命令启动；ORM 管理 SQLite 方便；AI SDK 生态好 |
| 数据库 | SQLite（含 FTS5 全文检索） | 单文件、零运维、易备份 |
| 前端 | Vue 3 + Vite + Pinia | 组件化开发效率高，生态成熟 |
| 可视化 | ECharts（关系图 / 雷达图 / 热力图） | 一个库覆盖知识图谱与统计图表 |
| AI | OpenAI 兼容 API（可配 base_url，兼容 DeepSeek / 通义等） | 只做批改与错因分析；key 本地配置 |
| 导入 | Excel 模板 + JSON + OCR 辅助（PDF 电子版真题） | 兼容现成题库整理输出 |

### 3.3 逻辑模块划分
- 后端（FastAPI routers）：knowledge / question / exam / wrong / plan / stats / essay / ai / import / backup。
- 前端（Vue 页面）：知识库 / 知识图谱 / 题库 / 模拟考试 / 错题本 / 计划 / 统计 / 论文 / 设置。

### 3.4 核心流程（三个闭环）
1. **学习闭环**：浏览知识点 → 图谱看关联 → 做关联例题 → 反馈掌握度。
2. **考试闭环**：组卷 → 限时作答 → 判分 → 报告（得分率 / 薄弱点）→ 错题入库 + 计划调整。
3. **错题闭环**：错题 → 归因（5 类）→ 反思 → 关联知识点 → SM-2 调度 → 重做 → 升级 / 降级。

## 4. 数据模型设计（核心表）

### 4.1 知识域
- knowledge_points(id, parent_id, name, code大纲编号, subject所属科目, description, memo, mastery掌握度0-100)
- knowledge_relations(id, from_id, to_id, relation_type[prerequisite前置/related相关/contains包含/conflicts冲突/backbone主线], note)

### 4.2 题库域
- questions(id, qtype[choice单选/case案例/essay论文], subject(1/2/3), stem题干, options_json, answer_json, analysis解析, difficulty1-5, source_type[real真题/self自编/ai生成], source_year, status)
- question_items(id, question_id, seq, stem小问, answer, score评分点) —— 案例与论文的子问题、评分点
- question_knowledge(question_id, knowledge_id, weight关联权重) —— 一题多知识点加权，是「串联」的数据基础

### 4.3 考试域
- paper_templates(id, name, subject, duration_min, config_json题型题量规则) —— 可配置，适配考试形式变化
- papers(id, template_id, created_at) / paper_questions(paper_id, question_id, seq)
- attempts(id, paper_id, mode[practice练习/mock模拟/wrong错题重做], started_at, finished_at, total_score)
- answers(id, attempt_id, question_id, user_answer_json, is_correct, time_spent, ai_feedback_json)

### 4.4 错题与复习域
- wrong_questions(id, question_id, first_attempt_id, error_type[知识性/理解偏差/审题失误/方法错误/其他], reflection反思, status[new/reviewing/mastered], repetition, interval_days, ease_factor, next_review_at) —— SM-2 字段
- review_logs(id, wrong_question_id, reviewed_at, recalled是否回忆成功, note)

### 4.5 计划与统计域
- study_plans(id, date, phase阶段, task_type, target, done)
- 统计视图 kp_mastery：掌握度 = 综合（该知识点题目正确率 × 近期表现 × 复习次数）

### 4.6 论文素材域
- essay_materials(id, category[项目经历/架构决策/技术点/范文], title, content, tags)
- adr(id, title, status, context背景, decision决策, alternatives备选, consequences后果, date) —— 架构决策记录

### 4.7 关系总览
知识点 ↔(关系边) 知识点；题目 ↔(加权) 知识点；题目 → 试卷 → 作答 → 答案；错误答案 → 错题 → 复习记录；知识点 ← 掌握度 ← 作答统计。

## 5. 功能模块详细设计

### 5.1 知识库与知识图谱（知识点复习 / 串联）
- 三层树浏览：章 → 节 → 知识点；知识点详情页含定义 / 要点 / 易错点 / 关联题目 / 关联知识点 / 掌握度。
- 图谱视图：ECharts 关系图，可过滤关系类型（前置 / 相关 / 主线），主线高亮；薄弱知识点节点标红。
- 复习模式：点开知识点即可练其关联例题（学习闭环入口）。

### 5.2 题库管理与导入
- 导入管线（已确认真题为 PDF 电子版）：PDF 真题集 → OCR/人工整理 → 标准化（Excel 模板 / JSON schema）→ 校验（题干、答案、知识点必填）→ 导入。OCR 建议：本地 PaddleOCR / 在线服务二选一，先以人工整理为主、OCR 提速为辅。
- 提供 Excel 导入模板与 JSON 格式说明；支持批量粘贴录入 + 知识点标签。
- 检索：SQLite FTS5 全文搜索题干 / 解析 / 知识点。

### 5.3 模拟考试
- 试卷模板：综合知识 75 单选 / 150min；案例分析 约 5 大题 / 90min；论文 多题选一 / 120min（按当年通知可调）。
- 机考体验：全屏限时、进度条、题号导航、交卷确认。
- 判分策略：单选自动判分；案例 = 参考答案对照自评 + AI 要点命中辅助；论文 = AI 分档评分（结构 / 内容 / 结合实践 / 语言）+ 改进建议。
- 报告：总分、各章得分率、薄弱知识点 Top N，自动生成错题并插入复习计划。

### 5.4 错题本与反思（错题整理与思考）
- 错题自动收集（模拟考 / 练习均入库）。
- 归因向导：5 类错因 + 反思三问（当时怎么想的 / 正确思路是什么 / 下次如何避免）。
- SM-2 间隔复习：每天生成复习队列；重做正确 → repetition+1、间隔拉长；重做错误 → 降级并重新归因。
- 反复错的知识点自动高亮，反哺图谱标红与计划加急。

### 5.5 学习计划
- 以 2026-11 为 D-day 倒推，四阶段：基础学习（知识点过一遍）→ 分科真题精练 → 套卷模拟 → 错题冲刺 + 论文强化。
- 每日任务按知识点掌握度生成，支持打卡与完成统计。

### 5.6 统计与画像
- 正确率趋势、刷题量、时间分布、知识点掌握度热力图、按大纲域的能力雷达图。

### 5.7 论文专项
- 历年论文真题库；提纲模板（背景 / 项目介绍 / 架构设计 / 实施与评估 / 总结展望）。
- 个人素材库（项目经历 / 架构决策 / 技术点），写作时可引用；限时写作模拟 + AI 批改。

### 5.8 AI 能力（批改与分析优先，出题后置）
- 统一 AI 网关模块：可配 base_url / api_key / model；超时、重试、失败降级。
- AI 论文批改：结构化 JSON 输出（分维度分档分 + 逐段点评 + 改进建议）；成本控制 = 按需调用、结果缓存。
- AI 错因分析：输入题干 + 我的答案 + 正确答案 → 归因建议（人工确认后入库，不替代人工反思）。
- AI 出题（后置）：按薄弱知识点生成模拟题，人工审核后入库。
- 原则：所有 AI 输出可人工修订，保证数据质量。

## 9. 论文素材联动（本系统的隐藏红利）

系统架构设计师论文要求结合亲身项目实践。本系统开发全过程将产出：

**规则：每个架构决策写一条 ADR；每个模块完成后补一条「项目经历」素材。**

### ADR 模板
~~~

状态：proposed | accepted | superseded

### ADR-001（示例）：采用本地 Web 应用 + 分层架构
- 状态：accepted
- 背景：个人单机备考工具；数据资产本地化优先；需要知识图谱可视化与 AI 批改能力；希望技术栈简单可维护。
- 决策：浏览器 + FastAPI 本地后端 + SQLite，分层架构（表现 / 应用 / 领域 / 基础设施）。
- 备选：纯前端 PWA（数据管理与大规模题库导入能力弱，放弃）；在线多端服务（运维成本高、数据不在本地，放弃）。
- 后果：正面——部署简单、数据可控、易备份；负面——多设备同步需手动备份；AI 能力依赖网络与 API key。
- 日期：2026-02
