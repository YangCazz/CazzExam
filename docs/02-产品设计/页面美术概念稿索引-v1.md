## 一致性要求

1. 所有页面遵循 Ink 背景、Slate 面板、蓝色主操作、紫色案例、玉绿完成、琥珀提醒、珊瑚高风险的状态语义。
2. 左侧导航仅作为稳定定位工具；主内容区必须围绕当前学习决策，而非模块堆砌。
3. 页面首屏有且仅有一个主行动，次要操作降级为描边或文字操作。
4. 图中出现的日期、题量、分数、题目仅为示意数据；实现必须使用真实配置和学习记录。
5. 中文文字渲染仅作概念参考，落地时采用前端文本而不是将文字烘焙到图片中。
